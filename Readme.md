# 🚀 AI Workflow in Data Journey: 

> **การวิเคราะห์เสียงตอบรับจากลูกค้า (Text Sentiment Analysis)**
>
> การทำงางานกับข้อมูลอัตโนมัติครบวงจร: จาก **Google Forms** (รับความเห็นลูกค้า) $\rightarrow$ **Google Sheets** (แปลงและจัดเก็บข้อมูล) $\rightarrow$ **AI วิเคราะห์ความรู้สึก (No-Code & Low-Code)** $\rightarrow$ **สรุปผลเป็นกราฟ Dashboard ในแผ่นงานเดียว**

## 📌 วัตถุประสงค์การเรียนรู้ (Learning Objectives)

1. เข้าใจกระบวนการ **Data Journey** ทั้งระบบ: เริ่มจากการเก็บรวบรวมข้อมูลดิบ (Data Collection via Google Forms) ไปจนถึงการเปลี่ยนข้อมูลข้อความไร้โครงสร้าง (Unstructured Text) ให้เป็นหมวดหมู่ความรู้สึก `Positive`, `Neutral`, `Negative` (Structured Data)

2. ฝึกปฏิบัติการวิเคราะห์ข้อมูลความเห็น 2 รูปแบบตามระดับทักษะ:

   * **แนวทาง No-Code:** ใช้สูตร AI ในตัวของ Google Sheets (`=AI(...)` หรือ `=GEMINI(...)`) พิมพ์ลงเซลล์โดยตรง ไม่ต้องเขียนโค้ดและไม่ต้องติดตั้งส่วนเสริมใด ๆ

   * **แนวทาง Low-Code:** พัฒนาสูตร Custom Function ขึ้นมาใช้งานเองในชื่อ `=ANALYZE_TEXT(...)` ผ่าน Google Apps Script เชื่อมต่อกับ Gemini API (Free Tier)

3. เข้าใจแนวคิด **Rate Limits** (RPM, TPM, RPD) และแหล่งสืบค้นโมเดลของ Google AI

4. เข้าใจการบริหารจัดการ Data Persistence: การคัดลอกผลลัพธ์ไปวางแบบค่า (Values Only) ในชีตใหม่ เพื่อป้องกันสูตรคำนวณซ้ำ และตัดขาดจากภาระของ API Key

5. ฝึกสรุปผลข้อมูลด้วยสูตร `=COUNTIF()` และสร้างแผนภูมิวงกลม (Pie / Donut Chart) แสดงสัดส่วนความพึงพอใจ

### วิธีที่ 1: ผลการวิเคราะห์ 1 — แนวทาง No-Code (ใช้ฟังก์ชันในตัวของ Google Sheets)

1. คลิกที่เซลล์ **C2** แล้วพิมพ์สูตร:


   *(หรือสูตร: `=GEMINI("Classify sentiment strictly as Positive, Neutral, or Negative only", B2)` ตามรุ่นฟีเจอร์ในบัญชี)*

3. ลากจุด Fill Handle (มุมขวาล่างของเซลล์ C2) ลงมาจนถึงแถว **C11**

### วิธีที่ 2: ผลการวิเคราะห์ 2 — แนวทาง Low-Code (สร้างสูตร `=ANALYZE_TEXT(...)` ผ่าน Apps Script)

วิธีนี้สร้าง Custom Function ขึ้นมาเองโดยตรงผ่าน Google Apps Script ร่วมกับ Gemini API:

#### 3.1 ขอ API Key จาก Google AI Studio

1. เข้าไปที่ [aistudio.google.com](https://aistudio.google.com) ด้วยบัญชี Gmail ส่วนตัว (`@gmail.com`)

2. กด **Get API key** $\rightarrow$ **Create API key in new project**

3. คัดลอกรหัส Key เก็บไว้

#### 3.2 ใส่โค้ดใน Apps Script

1. ที่หน้า Google Sheets ไปที่เมนู **ส่วนขยาย (Extensions)** $\rightarrow$ **Apps Script**

2. ลบโค้ดเดิมทั้งหมด แล้ววางสคริปต์นี้:

```javascript
// นำ API Key ที่ได้จาก aistudio.google.com มาวางตรงนี้
const GEMINI_API_KEY = "วาง_API_KEY_ที่นี่";

// กำหนดโมเดลรุ่น Flash ที่ใช้งาน
const MODEL_NAME = "gemini-3.5-flash"; 

/**
 * วิเคราะห์ความรู้สึกจากข้อความความคิดเห็น (Low-Code Custom Function)
 * ตอบเฉพาะ: Positive / Neutral / Negative เท่านั้น
 * @param {string} text ข้อความความคิดเห็น
 * @return {string} ผลวิเคราะห์ความรู้สึก
 * @customfunction
 */
function ANALYZE_TEXT(text) {
  if (!text || text.toString().trim() === "") return "";

  const url = "https://generativelanguage.googleapis.com/v1beta/models/" + MODEL_NAME + ":generateContent?key=" + GEMINI_API_KEY;

  // Prompt สั้นกระชับ เพื่อประหยัด Token ขาเข้า
  const prompt = "Classify sentiment of this text strictly as Positive, Neutral, or Negative only: " + text;

  const payload = {
    contents: [{ parts: [{ text: prompt }] }],
    generationConfig: {
      temperature: 0.1,    // ผลลัพธ์แม่นยำ ไม่สุ่มคำตอบ
      maxOutputTokens: 5   // จำกัดคำตอบไม่เกิน 5 โทเคน ช่วยให้เร็วและประหยัดโควตา
    }
  };

  const options = {
    method: "post",
    contentType: "application/json",
    payload: JSON.stringify(payload),
    muteHttpExceptions: true
  };

  try {
    const response = UrlFetchApp.fetch(url, options);
    const json = JSON.parse(response.getContentText());

    if (json.candidates && json.candidates[0].content) {
      return json.candidates[0].content.parts[0].text.trim();
    }
    return "Error: ไม่พบผลลัพธ์";
  } catch (err) {
    return "Error: " + err.toString();
  }
}
```

3. กดไอคอน **บันทึก (Save)** (รูปแผ่นดิสก์)

4. กลับมาที่หน้าชีต ในช่อง **D2** พิมพ์สูตร:

   ```excel
   =ANALYZE_TEXT(B2)
   ```

5. กด **Enter** แล้วลากมุมขวาล่างของเซลล์ลงมาจนถึง **D11**

## 📊 ขั้นตอนที่ 4: สร้างชีตใหม่ วางผลแบบค่า (Values Only) และสร้าง Dashboard กราฟ

เพื่อป้องกันไม่ให้ชีตส่งคำขอเรียก AI ซ้ำซ้อนตอนส่งตรวจงาน และป้องกันปัญหา Error เมื่อแชร์ให้ผู้อื่น ให้ทำตามขั้นตอนดังนี้:

### 4.1 คัดลอกและสร้างชีตสรุปผลใหม่

1. ในชีตข้อมูลดิบเดิม (แผ่นงานคำตอบแบบฟอร์ม) ให้ลากเมาส์คลุมข้อมูลทั้งหมด:
   - คลุมตั้งแต่ **คอลัมน์ B ถึง D** (เซลล์ `B1:D11`)
   - กดคัดลอก: `Ctrl + C` (หรือ `Cmd + C` บน Mac)
2. มองที่แถบด้านล่างซ้ายของหน้าต่าง Google Sheets คลิกที่เครื่องหมายบวก **(+) "เพิ่มแผ่นงาน" (Add Sheet)** เพื่อเปิดชีตใหม่
3. ดับเบิลคลิกที่ชื่อแท็บแผ่นงานใหม่ แล้วตั้งชื่อว่า: **`Dashboard สรุปผล`**
4. คลิกที่เซลล์ **A1** ในชีตใหม่
5. **วางเฉพาะค่า (สำคัญมาก):**
   - คลิกขวาที่เซลล์ **A1** $\rightarrow$ เลือก **วางแบบพิเศษ (Paste Special)** $\rightarrow$ **ค่าเท่านั้น (Values only)**
   - หรือกดคีย์ลัด: `Ctrl + Shift + V` (หรือ `Cmd + Shift + V`)
   - *ผลลัพธ์:* สูตร `=AI(...)` หรือ `=ANALYZE_TEXT(...)` จะถูกแปลงเป็นข้อความธรรมดาอย่างถาวร ไม่ต้องกังวลว่าเปิดมาใหม่แล้วจะรันซ้ำหรือสูญหาย

### 4.2 สร้างตารางนับจำนวนสรุปผล

ในชีต `Dashboard สรุปผล` ให้สร้างตารางนับสรุปผลไว้ที่ช่วงเซลล์ **F1:G4** (โดยอ้างอิงข้อมูล Sentiment จากคอลัมน์ C):

### 4.3 สร้างแผนภูมิสรุปผลรายงาน (Data Visualization)

1. ลากเมาส์คลุมตารางสรุปตั้งแต่เซลล์ **F1 ถึง G4**
2. ไปที่เมนูแถบเครื่องมือด้านบน: **แทรก (Insert)** $\rightarrow$ **แผนภูมิ (Chart)**
3. ในแผงควบคุม **ตัวแก้ไขแผนภูมิ (Chart editor)** ทางด้านขวา:
   - แท็บ **ตั้งค่า (Setup)**: ตรงช่อง *ประเภทแผนภูมิ (Chart type)* ให้เลือกเป็น **แผนภูมิวงกลม (Pie Chart)** หรือ **แผนภูมิโดนัท (Donut Chart)**
   - แท็บ **ปรับแต่ง (Customize)**:
     - หัวข้อ *ชิ้นของแผนภูมิวงกลม (Pie slice)*: ปรับสีให้สื่อความหมาย (เช่น Positive = สีเขียว, Neutral = สีเทา/ฟ้า, Negative = สีส้ม/แดง)
     - หัวข้อ *ชื่อแผนภูมิและแกน (Chart & axis titles)*: ตั้งชื่อเป็น `"สัดส่วนความพึงพอใจลูกค้า Cha-Shabu Bar"`
4. ลากย้ายตัวแผนภูมิมาจัดวางไว้ข้างตารางสรุปผลให้อ่านง่ายและสวยงาม

## 📚 แหล่งดูโมเดล และทำความเข้าใจ Rate Limit

### 1. แหล่งตรวจสอบโมเดลล่าสุด (Model Catalog)

Google มีการอัปเดตรุ่นโมเดลเป็นระยะ สามารถตรวจสอบโมเดลที่ Active และพร้อมใช้งานได้จาก:

* **Documentation ทางการ:** [ai.google.dev/gemini-api/docs/models](https://ai.google.dev/gemini-api/docs/models)

* **หน้า Google AI Studio:** [aistudio.google.com](https://aistudio.google.com) (ดูที่แถบ Model Selector ด้านขวา)

### 2. ตัวย่อสำคัญเกี่ยวกับ Rate Limit (โควตาการใช้งาน)

หากยิงคำสั่งถี่เกินเพดาน ระบบจะคืนค่าข้อผิดพลาด **`429 (Resource Exhausted / Rate Limit Exceeded)`**:

| ตัวย่อ | คำเต็ม | ความหมาย | 
| ----- | ----- | ----- | 
| **RPM** | **Requests Per Minute** | **จำนวนครั้งที่ยิงเรียก API ได้ต่อ 1 นาที** (เช่น 15 RPM หมายความว่าห้ามลากสูตรเกิน 15 แถวพร้อมกันใน 1 นาที) | 
| **TPM** | **Tokens Per Minute** | **จำนวนโทเคนรวม (Input + Output) สูงสุดต่อ 1 นาที** | 
| **RPD** | **Requests Per Day** | **จำนวนครั้งที่ยิงเรียก API ได้สูงสุดต่อ 1 วัน** (โควตารีเซ็ตทุกเที่ยงคืนเวลาแปซิฟิก) | 
| **TPD** | **Tokens Per Day** | จำนวนโทเคนรวมสูงสุดที่อนุญาตให้ประมวลผลต่อ 1 วัน |

## 💡 คำถามสำคัญ & ทริกการจัดการระบบ (Best Practices)

### ❓ 1. ถ้าแชร์ส่งลิงก์ชีต ผลวิเคราะห์จะหายไหม? แล้วคนเปิดจะเห็น Key เราไหม?

* **เรื่องผลวิเคราะห์หาย:** หากทำตามขั้นตอนที่ 4 โดยคัดลอกมาวางเฉพาะค่า (**Paste Special > Values only**) ในชีต Dashboard ผลลัพธ์จะกลายเป็นข้อความธรรมดาถาวร คนเปิดจะเห็นข้อมูลและกราฟครบถ้วน 100% โดยที่ AI ไม่ต้องรันใหม่
* **เรื่อง API Key:**
  * หากแชร์แบบ **"ผู้ดู" (Viewer)**: คนเปิดจะไม่สามารถเข้าเมนู Extensions > Apps Script ได้ จึงไม่เห็นโค้ดและไม่เห็น Key
  * หากแชร์แบบ **"ผู้แก้ไข" (Editor)**: คนเปิดจะเข้าดูโค้ดและเห็น Key ได้ ดังนั้นก่อนแชร์สิทธิ์แก้ไข ให้ลบรหัส API Key ใน Apps Script ออกก่อน

### ❓ 2. ทริกประหยัด Token และไม่ให้ระบบรันเรื่อย ๆ

1. **ตัด Token ขาออก:** กำหนด `maxOutputTokens: 5` ในสคริปต์ เพื่อบังคับให้ตอบกลับมาสั้นที่สุดเพียงคำเดียว
2. **ใช้ Prompt ภาษาอังกฤษ:** ประหยัด Token ขาเข้ามากกว่าการสั่งด้วยภาษาไทยเกือบ 3 เท่า
3. **ป้องกันช่องว่างด้วย IF / ISBLANK:** ใส่สูตรป้องกันไม่ให้ AI รันหากไม่มีข้อความในแถวนั้น:
   ```excel
   =IF(ISBLANK(B2), "", ANALYZE_TEXT(B2))
   ```
4. **ทยอยลากสูตร:** หลีกเลี่ยงการลากสูตรรวดเดียวหลายสิบแถว เพื่อไม่ให้ความถี่ชนเพดาน RPM ของแพ็กเกจฟรี
